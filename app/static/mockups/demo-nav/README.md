# Demo navigation UI mockups
Three genuinely distinct design directions per demo-nav page type.
## Preview
- Index: [`/apt/mockups`](/apt/mockups)
- Individual: `/apt/mockups/{page}-{variant}` (e.g. `/apt/mockups/sitemap-a`)

## Variant families
| Family | Thesis | Aesthetic |
|--------|--------|----------|
| **A** — Campaign command center | Dark ops console — Clay × HubSpot density with monospace signal chips. | Dark ops |
| **B** — Product tour | Light editorial tour — Stripe-docs whitespace with Fraunces serif accents. | Light editorial |
| **C** — Sales deck | Bold pitch deck — gradient heroes, Syne display type, motion-forward cards. | Bold pitch |
